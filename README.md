BuyerPlugin — Система скупщиков для Minecraft

Продвинутая система скупщиков предметов с уровнями, редкостью и автогенерацией цен

Версия: 1.0.0
Minecraft: 1.21.x (PaperMC 1.21.1)
Java: 21
Автор: KALINKA-games

Описание

BuyerPlugin — это мощный и гибкий плагин для серверов Minecraft на базе PaperMC 1.21.x, который добавляет на сервер интерактивную систему скупщиков предметов. Игроки могут продавать ресурсы различным специализированным NPC, получать игровую валюту и повышать свой уровень для получения множителей к ценам.

Основные возможности
7 специализированных скупщиков — каждый принимает определённые категории предметов.
Автогенерация предметов — общий скупщик автоматически принимает ВСЕ предметы из Minecraft с разумными базовыми ценами.
Система уровней — 5 уровней прогрессии с множителями цен (от x1.0 до x3.0).
Система редкости — 5 уровней редкости с цветовой индикацией в GUI.
Автообновление цен — цены динамически обновляются каждый час с небольшой рыночной вариацией (±10%).
Красивый GUI — интуитивно понятный интерфейс с пагинацией и поддержкой кастомизации.
Гибкая настройка — полная кастомизация через config.yml.
Поддержка Vault — бесшовная интеграция с любыми экономическими плагинами.

Использование
Для игроков
Открыть меню скупщика: Введите одну из команд: /buyer, /miner, /farmer, /endbuyer, /netherbuyer, /fisherman или /sawingwood.
Продажа предметов:
ЛКМ по предмету — продать 1 штуку.
ПКМ по предмету — продать все такие предметы в инвентаре.
Изумрудный блок (в меню) — продать ВСЁ, что принимает данный скупщик.
Навигация в меню:
Стрелки влево/вправо — переключение страниц.
Барьер — закрытие меню.
Для администраторов
Настройка скупщика: Используйте команду: /buyersetup [id] (Примеры: /buyersetup buyer, /buyersetup miner).
Управление в меню настройки:
ЛКМ по предмету — изменить цену (введите число в чат).
ПКМ по предмету — удалить предмет из списка скупщика.
Наковальня — добавить предмет, который держите в руке, в список скупщика.
Система уровней

Игроки получают опыт (XP) за каждую продажу и повышают свой уровень, что увеличивает доход:

Уровень	Название	Множитель цены	Требуется XP
1	Новичок	x1.0	0
2	Торговец	x1.25	1,000
3	Купец	x1.5	5,000
4	Магнат	x2.0	15,000
5	Легенда	x3.0	50,000

Пример: Если базовая цена алмаза составляет 120$, то игрок уровня "Легенда" получит 360$ за каждый проданный алмаз!

Система редкости

Каждый предмет имеет уровень редкости, который визуально отображается в GUI и влияет на итоговую цену:

Редкость	Цвет текста	Множитель
Обычный	&f (Белый)	x1.0
Необычный	&a (Зелёный)	x1.5
Редкий	&b (Синий)	x2.5
Эпический	&d (Фиолетовый)	x5.0
Легендарный	&6 (Золотой)	x10.0
Настройка

Все параметры гибко настраиваются в файле plugins/BuyerPlugin/config.yml.

Основные разделы конфигурации:

1. Система редкости

yaml
Копировать
rarity:
  common:
    name: "Обычный"
    multiplier: 1.0
    color: "&f"
  # ... другие уровни редкости

2. Автогенерация цен

yaml
Копировать
auto-generation:
  enabled: true
  base-prices:
    wooden-tool: 2.0
    iron-tool: 20.0
    diamond-tool: 250.0
    # ... базовые цены для категорий предметов

3. Уровни прогрессии

yaml
Копировать
levels:
  1: { name: "Новичок", multiplier: 1.0, required-xp: 0 }
  2: { name: "Торговец", multiplier: 1.25, required-xp: 1000 }
  # ... другие уровни

4. Конфигурация скупщиков

yaml
Копировать
buyers:
  buyer:
    title: "&8[&6Скупщик&8]"
    auto-generate: true  # Автогенерация всех предметов Minecraft
    items:
      DIAMOND: { price: 120.0, rarity: "rare" }
      # ... кастомные предметы

5. Сообщения (поддержка PlaceholderAPI)

yaml
Копировать
messages:
  prefix: "&8[&6Скупщик&8] "
  sold-one: "&aПродано 1 шт. &e%item% &aза &6%price%$&a!"
  # ... другие сообщения
Установка

Примечание: Плагин уже скомпилирован и полностью готов к использованию. Сборка из исходного кода или наличие Maven/JDK не требуются.

Возьмите готовый файл BuyerPlugin-1.0.0.jar.
Поместите его в папку plugins/ вашего сервера.
Перезапустите сервер (или выполните /reload, хотя полный перезапуск рекомендуется для корректной инициализации).
При необходимости отредактируйте файл plugins/BuyerPlugin/config.yml под экономику вашего сервера.

Автообновление цен

Каждый час (интервал настраивается) плагин автоматически:

Обновляет цены на все предметы с небольшой вариацией (±10% от базовой цены).
Опционально отправляет уведомление всем игрокам в чат.
Сохраняет актуальные данные в data.yml.

Настройка интервала:

yaml
Копировать
refresh-interval-hours: 1  # Обновлять цены каждый час
Решение проблем
Проблема	Возможное решение
"У вас нет этого предмета!"	Убедитесь, что предмет находится в инвентаре и данный скупщик настроен на его приём.
Деньги не начисляются	Установите плагин Vault и совместимый экономический плагин (например, EssentialsX Economy).
Ошибки в консоли при запуске	1. Проверьте, что используется Java 21.<br>2. Убедитесь, что версия ядра — PaperMC 1.21.x.<br>3. Проверьте права доступа ОС к папке plugins/BuyerPlugin/.
